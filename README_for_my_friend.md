# For My Friend 💗

Personal greeting website with animated hearts, RU/UZ languages, 30 reactions, an escaping button, and optional email notification.

**Branch:** `for-my-friend` (kept separate from the `main` site).

**Audio:** The background track is `dont-worry-be-happy.mp3`. Both `index.html` and `momigim/index.html` point to this file at the **root of this branch**. You must add this MP3 separately. It is intentionally not in this GitHub branch yet. Only upload music you have permission to publish.

Mobile browsers require a tap before music can start. No embedded YouTube player is used.

**Publishing:** GitHub Pages currently serves the default branch's site, not this separate branch automatically. To publish without replacing the existing 8_march site, use a different GitHub Pages repository for this project.

For testing email notifications privately, add `?testmail=1` to a published version of the URL. FormSubmit may require email verification first.
